# 快速开始指南

## 5分钟快速部署

### 第一步：安装Rust

#### Windows用户
1. 访问 https://rustup.rs/
2. 下载并运行 `rustup-init.exe`
3. 按照提示完成安装
4. 重启终端

#### Linux/macOS用户
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
```

### 第二步：编译项目

```bash
cd ws-proxy-client
cargo build --release
```

编译需要几分钟，请耐心等待。

### 第三步：配置服务器

编辑 `config.toml` 文件：

```toml
[server]
address = "你的服务器地址.com"    # 改成你的服务器
port = 443
uuid = "你的UUID"                # 改成你的UUID
ws_path = "/"

[tls]
randomize_fingerprint = true     # 保持开启
enable_ech = true
sni = "你的服务器地址.com"        # 改成你的服务器

[proxy]
socks5_enabled = true
socks5_bind = "127.0.0.1"
socks5_port = 1080

http_enabled = true
http_bind = "127.0.0.1"
http_port = 8080
```

**重要**：必须修改以下三项：
1. `server.address` - 你的服务器地址
2. `server.uuid` - 你的UUID（与服务端一致）
3. `tls.sni` - 你的服务器地址（通常与address相同）

### 第四步：运行客户端

#### Windows
```powershell
.\target\release\ws-proxy-client.exe
```

#### Linux/macOS
```bash
./target/release/ws-proxy-client
```

看到以下输出表示成功：
```
🚀 WebSocket Proxy Client starting...
✅ Connected to server
✅ Yamux multiplexing initialized
🚀 SOCKS5 proxy listening on 127.0.0.1:1080
🚀 HTTP proxy listening on 127.0.0.1:8080
✅ All proxy servers started
Press Ctrl+C to stop
```

### 第五步：测试代理

#### 测试SOCKS5
```bash
curl --socks5 127.0.0.1:1080 https://www.google.com
```

#### 测试HTTP代理
```bash
curl --proxy http://127.0.0.1:8080 https://www.google.com
```

如果能正常访问，说明代理工作正常！

## 浏览器配置

### Chrome/Edge
1. 打开 设置 → 系统 → 打开代理设置
2. 手动代理配置：
   - 代理服务器：`127.0.0.1`
   - 端口：`1080`（SOCKS5）或 `8080`（HTTP）
   - 类型：SOCKS5 或 HTTP

### Firefox
1. 设置 → 网络设置 → 手动代理配置
2. SOCKS主机：`127.0.0.1`
3. 端口：`1080`
4. 选择：SOCKS v5

## 常见问题

### Q1: 编译失败
**A**: 确保Rust版本 ≥ 1.83
```bash
rustc --version
rustup update
```

### Q2: 连接失败
**A**: 检查三项配置：
1. 服务器地址是否正确
2. UUID是否与服务端一致
3. 服务器是否正在运行

### Q3: 端口被占用
**A**: 修改配置文件中的端口号：
```toml
[proxy]
socks5_port = 1081  # 改成其他端口
http_port = 8081    # 改成其他端口
```

### Q4: 如何查看详细日志
**A**: 使用 `--verbose` 参数：
```bash
ws-proxy-client --verbose
```

## 核心特性

✅ **TLS指纹混淆** - 规避JA3/JA4检测  
✅ **WebSocket + TLS1.3** - 安全传输  
✅ **Yamux多路复用** - 高效连接
